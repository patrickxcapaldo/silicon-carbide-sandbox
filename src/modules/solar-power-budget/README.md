# Module 02: Solar Power Budget

An interactive, first-principles engineering model for one physical question: **What is the orbit-averaged electrical power generated by a solar array in Earth orbit, under realistic eclipse, pointing, efficiency, temperature, and degradation effects?**

The module provides deterministic, high-fidelity electrical generation calculations that compose directly into [`orbital-thermal-limits`](../orbital-thermal-limits) or downstream energy storage and satellite bus budgets.

---

## What It Calculates

1. **Cell Temperature Derating:**
   $$\eta_{\text{temp}} = \eta_0 \left[1 + \gamma (T_{\text{cell}} - 28\text{ °C})\right]$$
   Evaluates how operating array temperature (typically 50–90 °C in full sunlight) reduces multi-junction GaAs or Silicon bandgap efficiency.

2. **Radiation & Aging Degradation:**
   $$\eta_{\text{EOL}} = \eta_{\text{temp}} (1 - r_{\text{deg}})^{\Delta t}$$
   Accounts for trapped proton/electron fluence across Van Allen belts and coverglass darkening over the mission lifespan.

3. **Balance of System (BOS) & Pointing:**
   Combines cell packing density, coverglass transmission, blocking diode drops, harness ohmic resistance, MPPT/PCDU power electronics efficiency, and solar array drive tracking accuracy $\cos(\theta)$.

4. **Keplerian Orbital Eclipse:**
   Integrates uniform mean-anomaly propagation with cylindrical shadow geometry to compute true time-weighted sunlit fraction $f_{\text{sunlit}}$ and orbit eclipse duration.

5. **Orbit-Averaged Power & Energy:**
   $$P_{\text{avg}} = P_{\text{sunlit}} \cdot f_{\text{sunlit}}$$
   $$E_{\text{orbit}} = P_{\text{avg}} \cdot T_{\text{orbit}}$$

## Composable Programmatic Usage

```ts
import { solarPowerBudget } from './sandbox/module';
import { orbitalThermalLimits } from '../orbital-thermal-limits/sandbox/module';

// 1. Calculate high-fidelity solar generation
const solar = solarPowerBudget.run({
  solarArrayAreaM2: 8,
  baseCellEfficiency: 0.30,
  cellOperatingTempC: 65,
  missionDurationYears: 5,
  orbitAltitudeKm: 600,
  orbitInclinationDeg: 97.8,
  orbitRaanDeg: 68.7,
});

console.log(`Average Power: ${solar.values.orbitAveragePowerW.toFixed(1)} W`);
console.log(`Sunlit Fraction: ${(solar.values.orbitSunlitFraction * 100).toFixed(1)}%`);

// 2. Feed directly into orbital-thermal-limits
const thermal = orbitalThermalLimits.run({
  externalGeneratedPowerW: solar.values.orbitAveragePowerW,
  computeWattsRequested: 700,
  radiatorArea: 4,
});

console.log(`Power Deficit: ${thermal.values.powerDeficitW.toFixed(1)} W`);
```
